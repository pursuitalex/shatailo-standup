# Єгор Шатайло — стендап one-pager

Односторінковий awwwards-style сайт-концепт для перегляду сольних стендап-концертів **Єгора Шатайла**.

Динаміка надихнута [rockhall.com](https://rockhall.com/), контент — із [shatailo.com](https://shatailo.com/).

## Стек

- Vanilla HTML / CSS / JS (без збірки)
- [Three.js](https://threejs.org/) — 3D hero-сцена (прожектор, мікрофон, пил у промені)
- [GSAP](https://gsap.com/) + ScrollTrigger — анімації, горизонтальний пін-скрол, reveal, магнітні кнопки

## Секції

Hero → Сольники → Про Єгора → Стендап-тур → Мерч → Футер.
Кожен сольник відкриває модалку з трейлером (YouTube), кнопка «Придбати» веде на сторінку покупки на shatailo.com.

## Запуск локально

Потрібен статичний сервер (ES-модулі не працюють із `file://`):

```bash
npx serve .
```

Далі відкрити вказаний `http://localhost:<port>`.

## Деплой

Статичний сайт — Vercel віддає файли з кореня без збірки (`index.html` в корені).
