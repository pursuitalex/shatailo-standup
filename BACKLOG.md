# Backlog — що ще треба додати

Цей файл фіксує функціонал, який поки реалізовано **як концепт/заглушку** або **ще не зроблено**.
Коли пункт реально реалізовано — **видаляй його з цього файлу**.

**Статус проєкту:** концепт-редизайн, статичний сайт (Vercel), без бекенду.
Кошик / акаунт / оформлення — клієнтський **mock** (`localStorage`, `js/store.js`).

---

## 🟡 Заглушки (працює як демо, але не по-справжньому)

- **Авторизація** — вхід через Google і email/пароль **фейкові** (нічого не перевіряється, дані нікуди не йдуть).
  → Треба реальний провайдер: **Supabase Auth** або Firebase.
- **Оплата / оформлення** — мок: сабміт показує «Замовлення прийнято», **без реальної оплати**.
  → Треба реальний шлюз: **WayForPay / Fondy** + серверна частина.
- **Кошик** — у `localStorage` браузера (не синхронізується між пристроями/сесіями).
  → Треба БД (**Supabase**).
- **Повне відео** — у кабінеті куплені сольники відкриваються у плеєр-модалці, але показано **фрагмент**
  (YouTube-трейлер), а не реальне повне відео (воно на shatailo.com).
  → Треба відтворення реального повного відео (захищений плеєр/хостинг).
